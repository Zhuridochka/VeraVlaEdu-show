# Landing Page with animation "VeraVla edu" online educational academy 
## This site is an impressive example of modern web design and functionality. It is designed to teach users of the basics and advanced capabilities of artificial intelligence, providing an intuitive and attractive custom experience.

🔗 **Demo:** https://zhuridochka.github.io/VeraVlaEdu-show/home.html

## Key features:
  Burger menu: The universal menu, which turns into a "burger" when reducing the width of the screen provides convenient navigation on mobile devices.
  Animated buttons: Users can interact with attractive animated buttons that add speakers and interactivity.
  Adaptive elements: moving elements disappear, and appear depending on the width of the screen, creating an adaptive and intuitive interface.
  Paralax effect:  Use parallax effect to create depth and visual appeal.
  Poppes with feedback form:  Convenient posters for quick communication with users.
  Real time: Ability to contact a WhatsApp chat or call.
  Various sliders: Use of several sliders to demonstrate training content.
  Compliance with BEM-methodology: All Code classes and structure are maintained by BEM-methodology to ensure modularity and reuse components.
  Semantic layout: Using semantic HTML tags to improve accessibility and SEO.
